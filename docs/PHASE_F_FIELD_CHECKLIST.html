5 · SAFETY & MEASUREMENT NOTES
  • Dry-run (no paint) precedes every live pass — nozzle capped/disconnected on run #1 of each mode. Never arm-and-walk-away.
  • Param sets are runtime and take effect next tick; no restart needed. A restart resets them to default-OFF.
  • Handshake is compound: the auto path needs RPP progress_publish_enabled + point_handshake_enabled AND spray consume_rpp_progress all ON. Any one OFF ⇒ frozen fixed-timer fallback (no error, no crash) — if the handshake "does nothing", check all three with ros2 param get.
  • Proof gates, never replaces: if /rpp/progress goes stale the spray node reverts to its own /path geometry — the valve has no hard dependency on the RPP. That fallback is itself a PASS criterion (§2 G2).
  • Measure driven pose against the raw /path, never /rpp/debug[0] (error vs the conditioned path — hides the vertex bug) and never /spray/debug[5] (nozzle xtrack).
  • Node names: spray = /spray_controller, controller = /rpp_controller. If spray does not fire, read /spray/status.safety_reason first — it names the exact blocking gate (disarmed / not OFFBOARD / gps / pivot / xtrack).
  • Manual advance is POST /api/spray/point/advance {expect_index}; expect_index must equal /api/spray/status.point.rpp_point_index or the RPP ignores it (stale-tap guard). The frontend "Next point" button is a separate repo — out of scope here; drive it by curl.
  • DoD per flag (G6): field A/B must show ≥ frozen. Anything that does not beat frozen stays default-OFF; only a winner is flipped to default and merged to baseline_master.
  • All G2–G5 code + the CSV point flow are bench/in-env verified only; this session is their first field validation. Log anything unexpected against the run.
